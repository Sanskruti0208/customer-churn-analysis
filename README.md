# 📊 Customer Churn Analysis Dashboard

An end-to-end Data Analytics and Machine Learning project built using Python, Streamlit, Pandas, Plotly, and Scikit-Learn.

This project analyzes telecom customer churn data to identify high-risk customers, generate business insights, estimate revenue impact, and predict future churn probability using Machine Learning.

---

## 🚀 Features

- Data Cleaning & Preprocessing
- KPI Dashboard
- Interactive Filters
- Business Insights Generation
- Customer Segmentation
- High-Risk Customer Detection
- Retention Recommendation Engine
- Revenue Impact Analysis
- Churn Prediction ML Model
- Interactive Visual Analytics Dashboard

---

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Plotly
- Streamlit
- Scikit-Learn
- GitHub
- Azure Cloud

---

## 📈 Key Insights

- Month-to-month customers churn the most
- Fiber optic users show high churn probability
- Electronic check users are high-risk customers
- Customers with low tenure churn earlier
- Long-term contracts significantly reduce churn

---

## 🤖 Machine Learning

Implemented a Random Forest Classifier to predict customer churn with approximately 81% model accuracy.

---

## 💼 Business Value

This project helps businesses:

- Reduce customer churn

- Identify risky customer segments

- Make data-driven business decisions
